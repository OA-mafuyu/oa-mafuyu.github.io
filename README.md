# 梗知识答题——但是缝合版

一个融合答题与小游戏的交互式网页项目，在答题间隙插入小游戏来争取额外时间。


## 功能概览

### 整体结构

```
首页 → 答题→ 结算页
       ↓ 每 5 题触发一次
     小游戏环节（获取奖励时间）
```

- **答题模式**：选择题库后开始限时答题，初始 60 秒倒计时
- **小游戏模式**：从首页直接进入小游戏，自由游玩
- **设置**：可开关音乐、音效、小游戏环节

---

## 答题玩法

1. 在首页点击「开始游戏」→「答题」→ 选择题库 →「开始答题」
2. 每道题 4 个选项，选项顺序由**种子随机**决定
3. 答对进入下一题，答错显示动画后继续
4. 倒计时归零或答完所有题目则游戏结束
5. 按 `ESC` 可随时退出

### 种子系统

- 每局答题开始时生成一个随机种子，显示在左上角
- 种子决定：题目顺序、每道题的选项排列、小游戏出现顺序
- 小游戏前 N 次出现（N = 小游戏数量，即 2）保证不重复

## 小游戏 1 · 霓虹跑酷 (Neon Rush 3D)

3D 无尽跑酷游戏，玩家在三条车道上奔跑躲避障碍。

### 操作

| 按键 | 功能 |
|------|------|
| `←` `→` / `A` `D` | 变道 |
| `↑` / `空格` | 跳跃（空中再按 = 二段跳 + 前空翻） |
| `↓` | 滑铲（过矮栏和悬空板） |
| `P` | 暂停 |
| `M` | 静音 |

### 障碍物

| 类型 | 通过方式 |
|------|----------|
| 矮栏 (barrier) | 蹲下滑铲 或 跳跃 |
| 悬空板 (overhead) | 蹲下滑铲 |
| 高墙 (block) | 跳跃 或 变道 |
| 双宽障碍 (wide) | 变道避开 |
| 移动高墙 (mover) | 左右滑动，需判断时机 |
| 蓝色高台 (platform) | 可站上去奔跑，金币排列其上 |

### 道具

| 道具 | 效果 |
|------|------|
| 护盾 ◈ | 抵挡一次碰撞死亡，撞碎障碍 +15 分 |
| 磁铁 ◎ | 持续 8 秒，吸附范围 4.2m，自动收集金币 |
| 无敌 ✸ | 持续 15 秒，撞碎障碍 +30 分 |

### 计分

- 基础分 = 速度 × 时间（速度从 13 逐渐加速至最大值 30 m/s）
- 收集金币：10 分 × 连击倍率（最高 ×5）
- 擦身而过：+5 分
- 每 400 分里程碑：SPEED UP

### 奖励时间（从答题进入时）

| 分数 | 答题加时 |
|------|----------|
| ≥ 2,500 分 | +5 秒 |
| ≥ 5,000 分 | +10 秒 |
| ≥ 10,000 分 | +15 秒 |

### 场景切换

在 2,000 / 5,000 / 8,000 分时自动切换主题场景：
霓虹都市 → 荧光雨林 → 极光雪原 → 落日沙海

## 小游戏 2 · 霓虹飞驰 (Neon Rush 3D)

3D 太空飞行游戏，驾驶飞船在霓虹隧道中穿梭。

### 操作

| 按键 | 功能 |
|------|------|
| `A` `D` / `←` `→` | 转向 |
| `W` / `↑` | 推进加速 |
| `P` | 暂停 |
| `M` | 音乐开关 |
| `R`（结算时） | 快速重开 |
| `Esc` | 返回主页 |

触屏设备支持拖动操控。

### 对象与道具

| 类型 | 说明 |
|------|------|
| 二十面体障碍 | 碰撞即死 |
| 锥体障碍 | 碰撞即死 |
| 横梁障碍 | 碰撞即死 |
| 晶石 ◆ | 收集 +60 分 |
| 加速环 | 穿越 combo+1，boost 1.6s |
| 护盾 | 持续 6 秒，抵挡一次碰撞 |
| 磁铁 | 持续 8 秒，吸附晶石 |
| 双倍 | 持续 10 秒，分数 ×2 |
| 缓时 | 持续 6 秒，速度 ×0.55 |
| 星星 | 直接 +300 分 |

### 计分

- 分数 = 速度 × 时间 × 0.12 × (1 + combo × 0.25) × (双倍道具 ×2)
- 速度范围：46 ~ 150 km/h

### 奖励时间（从答题进入时）

与小游戏 1 相同：2,500 分 +5 秒 / 5,000 分 +10 秒 / 10,000 分 +15 秒

### 后端存储（可选）

运行 `minigame2/server.py` 可将成绩和成就同步到 SQLite 数据库。不运行也能正常游玩，数据保存在浏览器本地。
